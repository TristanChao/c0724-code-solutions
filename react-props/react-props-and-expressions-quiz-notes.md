# react-props-and-expressions-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What are props in React?
  - props (short for properties) are arguments passed to component function calls, styled in a way that is similar to HTML attributes
- How do you declare and access props in a component?
  - props are declared by creating a type, usually called Props, that is an object containing the prop names and their types
  - props are accessed by adding a parameter to the component function that de-structures an anonymous object literal into variables with the same names as the props
- How do you pass props to a component?
  - props are declared by typing the prop name, = operator, and the value within the component's tag in the JSX where it is called
- How do you write JavaScript expressions in JSX?
  - by surrounding the expression with curly braces
