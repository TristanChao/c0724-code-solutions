# express-intro-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is Express useful for?
  - Express is a web server framework for Node
- How does Express fit into a full-stack web application?
  - Express is part of server/backend
- How do you add `express` to your package dependencies?
  - `npm install --save-dev @types/express`
- What Express application method starts the server and binds it to a network `port`?
  - listen
- What is a network `port`?
  - a network port is a virtual endpoint for network connections
  - ports are software-based and managed by the OS
  - each of the computer's ports are associated with a specific process or service
