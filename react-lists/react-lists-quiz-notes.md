# react-lists-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- When would we want to dynamically create a list of React components?
  - dynamically creating a list of components will help with reusability and be necessary for lists that can be modified by the user
- Why is it important for React components to be data-driven?
  - one of the biggest reasons to use React components is for their reusability, and being data-driven is what allows them to be reused
  - if components are hard-coded, they are a lot less reusable
- What `Array` method is commonly used to create a list of React components?
  - the `map` method
- Why do components in a list need to have unique keys?
  - keys help React keep track of items when they are being changed
- What is the best value to use as a "key" prop when rendering lists?
  - the best value for a key prop is a unique id string
