# react-jsx-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is JSX?
  - JSX is a way of creating DOM elements in a way that closely resembles HTML format, making it quicker to write and easier to read
- How does React use JSX to render components?
  - React uses JSX to render components by converting it to HTML, then pushing it to the DOM
