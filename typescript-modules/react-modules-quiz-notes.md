## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What are modules?
  - a module is a portion of code in an external file that has a specific purpose
- What is the difference between named and default imports?
  - default imports can be renamed upon importing
  - named imports have to use the name that was exported from the other file
- What is the difference between named and default exports?
  - there can only be one default export per file
  - there can be any amount of named exports in one file, but they all need different names
