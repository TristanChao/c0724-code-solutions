# react-events-quiz-notes

## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- What is an "event" in React?
  - an event in React is similar in concept to JavaScript events: it is an action that is triggered by something happening on the web page, commonly a user interaction
- What is an "event handler"? Which component declares the handler?
  - an event handler is a function that executes code when an event is triggered
  - it is good practice for the handler to be declared in the app component
- How do you pass an event handler to a React component?
  - you create a custom event handler prop and pass the event handler in as the value
- What is the naming convention for event handlers?
  - "handle" followed by a capital letter
- What is an "event handler prop"? Which component declares the prop?
  - an event handler prop is a prop from which a parent element passes in an event handler
  - the child component declares the prop
- What are some custom event handler props a component may wish to define?
  - onClick
- What is the naming convention for custom event handler props?
  - "on" followed by a capital letter
