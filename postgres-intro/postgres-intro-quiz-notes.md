## Quiz Questions

Answer the following questions in the provided markdown file before turning in this exercise:

- Why do we use databases in Web development?
  - databases can be used to distribute data to multiple users from a centralized location
  - it allows for data to be saved across multiple devices, as opposed to local storage, which cannot be accessed from a different device
- What is PostgreSQL and what are some alternative relational databases?
  - postgresql is a relational database system
  - some alternatives are mysql, sql server, and oracle
- What are some advantages of learning a relational database?
  - relational databases are widely used and good for storing data that that is interrelated
  - relational databases store data in a way that minimizes data corruption
- What is one way to see if PostgreSQL is running?
  - sudo service postgresql status
